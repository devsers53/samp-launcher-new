## 2. SA:MP — the modification

**San Andreas Multiplayer** ("SA:MP") is a multiplayer mod for Grand Theft
Auto: San Andreas. It allows a large number of players to play together
online on community-run servers. The project was originally created by
community developers and is distributed freely.

The launcher in this repository:

- does **not** contain any game content, art, models, or audio from GTA: San
  Andreas;
- does **not** contain SA:MP's proprietary runtime (`samp.dll`), the game
  executable, or the game itself;
- only automates a dialog-based launch of the game plus the SA:MP client
  (`samp.exe` / `samp.dll`) on the player's own, legally owned copy of the
  game;
- connects to third-party community servers for its master server list.

**You must own a legitimate copy of Grand Theft Auto: San Andreas to use this
launcher.** This software does not distribute or assist in circumventing any
copy protection.

## 3. Required third-party components

Standalone **SA:MP client files** (most importantly `samp.dll`, which the
launcher loads into `gta_sa.exe`) are required to actually connect to servers.

- The launcher **does not bundle** `samp.dll`.
- If `samp.dll` is missing from the game directory, the launcher will display
  an error and will **not** be able to join a server.
- Obtain SA:MP client files only from trusted, official sources.
